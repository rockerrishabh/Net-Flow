Telemetry Built for Enthusiasts and Developers

Most bandwidth utilities run heavy web runtimes or clunky system tray menus. Net Flow lives natively where you want it, with zero distraction.

🪟

Native Windows 11 Widgets

Directly integrates into the Windows 11 Widgets Board (Win + W) with native Adaptive Cards v1.6 across Small, Medium, and Large dimensions.

📈

Mirrored Dual-Stream Waveforms

In-memory supersampled rasterizer draws download traffic above the baseline in cyan (#38D9F0) and upload below in amber (#FFB020) with glowing pulse nodes.

⚡

Native IP Helper Backend

Bypasses slow WMI and PowerShell wrappers by calling native Win32 GetIfTable2 APIs in asynchronous pure Rust.

🛜

Smart Active Adapter Detection

Auto-detects the primary default network interface with contextual badges: Wi-Fi with friendly SSID, Ethernet, Cellular, or VPN tunnels.

📱

Per-App Bandwidth Attribution

Identifies which applications are actively consuming throughput with compact rate formatting and generous process name budgets on Large widget cards.

🔒

100% Offline & Private

Contains zero telemetry, zero analytics, zero GPS coordinates, and makes zero network requests. Your data never leaves your computer.

Installation Options

Install directly from the Microsoft Store for automatic background updates, or build and sideload locally with one command.

One-Command Sideload Script
git clone https://github.com/rockerrishabh/net-flow.git && cd net-flow && powershell -ExecutionPolicy Bypass -File scripts/install.ps1

Automatically builds, provisions a local test certificate, creates an MSIX package, and registers the widget directly into the Windows 11 Widgets Board.
